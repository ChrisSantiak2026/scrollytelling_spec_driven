# Agent Directives & AI Workflow Management

## The AI Forward Engineer Mandate
[cite_start]In this project, AI is utilized as a **high-speed implementation engine**, while I act as the **Architect and Auditor** [cite: 74-75]. [cite_start]AI is never used mindlessly; every output is revised and validated against the technical Spec[cite: 74, 85].

## Management Protocol (The Control Loop)
For every phase of development, I manage my AI pair using the following loop:
1. **Context Loading:** Providing the Spec and Phase files before any code is written.
2. **The Hand-off:** Explicitly directing the AI to implement a scoped task.
3. **Validation:** Running `npm run dev` and `npm run lint` in Git Bash to check for "Spec-Drift" or technical debt.
4. **Audit:** Reviewing code for readability, performance, and adherence to the "Research Lab" aesthetic.
